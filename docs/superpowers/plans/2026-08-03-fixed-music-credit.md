# Fixed Music Credit Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Move the collapsed music attribution control from the footer flow to an unobtrusive fixed icon in the viewport's bottom-right corner.

**Architecture:** Retain the native `<details>` disclosure and all existing licensing links. Change only its summary markup and CSS positioning, with generated-site checks guarding the accessible label, hidden visible text, fixed corner placement, and responsive attribution panel.

**Tech Stack:** EJS, CSS, Node.js static-site checker, GitHub Pages.

## Global Constraints

- The collapsed control is fixed to the screen bottom-right and shows only a low-contrast `♫` icon.
- The control retains the accessible name `音乐版权` through `aria-label`.
- Full track, source, author, and CC BY 4.0 attribution remains available after expansion.
- The expanded panel opens to the left and above the icon, is at most 440px wide and 40vh high, and fits mobile screens with `calc(100vw - 24px)`.
- Do not add JavaScript, dependencies, resources, or eager music loading.
- Keep the existing fixed music player at the screen bottom-left.

### Task 1: Add failing generated-site checks

**Files:**
- Modify: `scripts/check-site.mjs`

**Interfaces:**
- Consumes: `_site/index.html` and `_site/styles/main.css` generated by `npm run build`.
- Produces: `npm run check` failures when the credit control is visibly wordy, not accessible, not fixed bottom-right, or lacks a responsive popup.

- [ ] **Step 1: Add semantic summary checks**

Extract the existing closed `details.music-attribution` HTML and require this literal summary markup:

```html
<summary aria-label="音乐版权"><span aria-hidden="true">♫</span></summary>
```

This catches a regression where “音乐版权” returns as visible footer text while keeping an accessible name.

- [ ] **Step 2: Add generated CSS contract checks**

Read `_site/styles/main.css` and require the attribution styles to include `position: fixed`, `right: 10px`, `bottom: 10px`, a popup width bounded by `min(440px, calc(100vw - 24px))`, and `max-height: 40vh`.

- [ ] **Step 3: Verify RED**

Run: `npm run build && npm run check`

Expected: build succeeds; check fails because the current summary contains visible text and the control remains in normal footer flow.

- [ ] **Step 4: Commit the checks**

```bash
git add scripts/check-site.mjs
git commit -m "test: cover fixed music credit control"
```

### Task 2: Implement fixed corner control and validate

**Files:**
- Modify: `theme/include/footer.ejs`
- Modify: `styles/main.css`

**Interfaces:**
- Consumes: the existing `details.music-attribution` and complete attribution link list.
- Produces: a fixed, icon-only disclosure control and a responsive popup panel.

- [ ] **Step 1: Replace the visible summary text**

Render the summary as:

```html
<summary aria-label="音乐版权"><span aria-hidden="true">♫</span></summary>
```

- [ ] **Step 2: Position the disclosure**

Set `.music-attribution` to `position: fixed`, `right: 10px`, `bottom: 10px`, and a z-index below the music player. Remove the normal-flow margin.

- [ ] **Step 3: Make the icon unobtrusive and accessible**

Give the summary a 32×32px click target, transparent background, 10–12px icon size, and low opacity. Raise opacity on hover and `:focus-visible`, and provide a visible keyboard focus outline.

- [ ] **Step 4: Create the responsive popup**

Position `.music-attribution-details` absolutely with `right: 0` and `bottom: 38px`; use `width: min(440px, calc(100vw - 24px))`, `max-height: 40vh`, internal scrolling, a readable background, border, radius, padding, and shadow.

- [ ] **Step 5: Verify GREEN**

Run: `npm run build && npm run check`

Expected: `Built 134 posts...`; `Verified 134 posts and 179 HTML pages.`; exit code 0.

- [ ] **Step 6: Validate with a local browser**

Confirm computed styles place the closed control at the viewport's bottom-right, its visible text is only `♫`, the five track links are hidden initially, and the links plus CC BY 4.0 appear after clicking.

- [ ] **Step 7: Commit implementation**

```bash
git add theme/include/footer.ejs styles/main.css
git commit -m "fix: tuck music credits into screen corner"
```
