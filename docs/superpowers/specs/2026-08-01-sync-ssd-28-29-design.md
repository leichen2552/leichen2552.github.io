# 同步 SSD 科普二十八、二十九

## 目标

将微信公众号导出目录中的 SSD 科普二十八和二十九完整同步到博客，并自动发布到 GitHub Pages。两篇文章保持公开，不增加付费阅读提示。

## 输入

- `2026-07-23 SSD科普二十八：一个Block坏了，FTL是怎么让它“消失”的？`
- `2026-07-29 SSD科普二十九：一条 Write 命令，是怎么进入 SSD 的？`

每篇输入均包含 `index.html`、封面以及正文图片。

## 导入方式

使用仓库现有的 `scripts/import-wechat.mjs`，从微信公众号 HTML 中提取 `#js_content`：

- 生成 `content/posts/ssd-2026-07-23.md` 和 `content/posts/ssd-2026-07-29.md`。
- 使用公众号原始发布时间。
- 设置标签为 `SSD`、`公众号`，并设置 `published: true`。
- 将封面和正文图片复制到各自的 `post-images/wechat-ssd/<slug>/` 目录。
- 把正文中的本地图片引用改为博客站内绝对路径，避免依赖微信图片外链。
- 保留微信公众号正文中的排版 HTML，外层沿用现有 `.wechat-article` 容器。

## 验证与发布

3. 检查两篇生成页面的标题、日期、标签、封面和所有本地图片链接。
4. 提交到独立分支，创建并合并拉取请求。
