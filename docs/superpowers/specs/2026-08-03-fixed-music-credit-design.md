# 屏幕右下角音乐版权入口设计

## 目标

把页脚正文流中的“音乐版权”入口移到浏览器视口右下角，使其默认极不显眼，同时保留可访问的完整 CC BY 4.0 署名。

## 交互与布局

- 继续使用原生 `<details>`，不增加 JavaScript或第三方依赖。
- 折叠状态下固定在屏幕右下角，仅显示低透明度的 `♫` 图标；通过 `aria-label="音乐版权"` 保留清晰的辅助技术名称。
- 图标使用约 32×32 像素的点击区域、10–12 像素图形和透明背景；鼠标悬停或键盘聚焦时才提高对比度。
- 展开后，完整署名浮层从图标向左上方弹出，最大宽度 440 像素、最大高度 40vh，并允许内部滚动。
- 移动端浮层宽度限制为 `calc(100vw - 24px)`，避免超出屏幕。
- 版权入口位于右下角，播放器继续位于左下角，二者互不遮挡。

## 内容与性能

- 保留五首曲目、Wikimedia Commons 文件页、Scott Buckley 作者链接和 CC BY 4.0 许可证链接。
- 默认不渲染可见的曲目文字；只有用户展开时才显示。
- 仅调整 HTML 标签内容和 CSS 定位，不引入资源请求，不改变播放器的延迟加载与 `preload: "none"`。

## 验证

1. 先增加回归检查，要求入口使用无文字的 `♫` 摘要、固定右下角定位和向左上展开的浮层，并确认旧实现失败。
2. 实施最小模板与 CSS 修改后运行完整构建和站点校验。
3. 本地浏览器确认默认仅有右下角小图标，点击后完整署名出现，关闭后再次隐藏。
4. 通过 PR 合并并等待 GitHub Pages 部署成功，再核验线上 HTML 和样式。
